1. Start the program.
2. Create arrays to store temperature, humidity and AQI values for 5 zones and 7 days.
3. Display the menu and ask the user to enter a choice.
4. If the user selects 1, get the input values for all zones and check whether they are valid.
5. If the user selects 2, display all the entered data.
6. If the user selects 3, calculate and display the average temperature, humidity and AQI of each zone.
7. If the user selects 4, check the risk conditions and count the number of risk days in each zone.
8. If the user selects 5, calculate the Green Index and rank all zones from highest to lowest.
9. If the user selects 6, display suitable environmental recommendations for each zone.
10. If the user selects 7, exit the program.
11. If the user enters a wrong choice, display an invalid choice message.
12. Repeat the menu until the user selects Exit.
13. Stop the program.
